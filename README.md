# Chef's Challenge

Chef's Challenge is a FiveM resource that adds a food preparation minigame system to your ESX-based server. This resource enhances the roleplay experience by requiring players to complete a series of minigames to successfully prepare food, adding a layer of challenge and immersion to your restaurant roleplay.

## Install

1. Download the resource from the GitHub repository.
2. Extract the files into your FiveM server's `resources` directory.
3. Add `start Chef's Challenge` to your server configuration file (`server.cfg`).
4. Ensure the resource is started after `es_extended`.

## Use

1. Players can start the minigame by using the command `/startminigame`.
2. The minigame will present a series of challenges that players must complete within a time limit.
3. Successfully completing all stages will reward the player with in-game currency.
4. Failing to complete the minigames will result in a notification that the food preparation was unsuccessful.
